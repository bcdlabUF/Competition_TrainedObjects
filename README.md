# Competition_TrainedObjects
Enclosed in this project are the MATLAB based scripts and data for the Boylan et al. study titled, “Competitive cortical prioritization emerges for trained objects across the first year of life” 

Boylan, M. R., Tebbe, A. L., Newland, J., Sanches Braga Figueira, J., Keil, A., & Scott, L. S. (2025). Competitive cortical prioritization emerges for trained objects across the first year of life. The Journal of Neuroscience, 45(42), e2314242025. https://doi.org/10.1523/JNEUROSCI.2314-24.2025
